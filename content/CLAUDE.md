# XTOKYO Wiki — 運用スキーマ

## このプロジェクトについて

「XTOKYO」は架空のNetflixシリーズ風YouTube動画制作プロジェクト。
YouTuber「（スミデ）」さんのクラブあるある総集編動画を題材に、
架空のキャラクターを登場人物としてキャスティングし、台本を作成する。

**最終成果物:**
1. プロモーション広告・ティザー映像(Netflix風)
2. ファスト映画紹介のような紹介映像

**現状:** 素材はすでに集まっている。台本・ネタの整理が未着手。

## フォルダ構造とルール

```
XTOKYO-wiki/
├── CLAUDE.md              ← このファイル
├── index.md               ← 全ページの目次(必ず最初に読む)
├── log.md                 ← 作業履歴(追記のみ)
├── raw/                   ← 原本。編集しない
│   ├── source-clips/      ← スミデさん動画の書き起こし・タイムスタンプメモ
│   └── assets/            ← 画像、参考資料など
└── wiki/                  ← ここはAIが書いて管理する
    ├── characters/        ← 架空キャラのプロフィールページ(1人1ファイル)
    ├── stories/           ← ネタ・エピソード案(1ネタ1ファイル)
    ├── scripts/           ← 台本(1本1ファイル、バージョンはファイル内で管理)
    └── deliverables/       ← 成果物の企画書(プロモ広告、ティザー、ファスト映画紹介)
```

## ページの役割

### `wiki/characters/*.md`
架空キャラクター1人につき1ページ。
含める項目: 名前、元ネタ(スミデ動画内の実在人物との対応があれば)、性格、口調、
役回り、登場するストーリー一覧(リンク)。

### `wiki/stories/*.md`
スミデ動画から拾った「ネタ」「あるあるエピソード」を台本化する前の断片。
1つのネタ = 1ファイル。元動画への参照(`raw/source-clips/`へのリンク)を必ず入れる。
関係する登場キャラクターをリンクする。

### `wiki/scripts/*.md`
実際の台本。複数のstoriesを組み合わせて1本にまとめたもの。
どのstoriesを元にしたか、どのdeliverableのための台本かを明記する。

### `wiki/deliverables/*.md`
成果物ごとの企画書。「プロモ広告」「ティザー」「ファスト映画紹介」など。
使う台本・キャラクター・尺・トーン(Netflixのどの作品のパロディかなど)を記載。

## ワークフロー

### Ingest(素材の取り込み)
新しい素材(スミデ動画、メモ、既存の台本下書きなど)を処理するとき:
1. `raw/`に素材を置く(すでに文字起こし済みならそのまま、動画ならメモを作る)
2. 内容を読み、ネタ・キャラクター候補を抽出
3. 該当する`wiki/stories/`や`wiki/characters/`のページを新規作成 or 更新
4. `index.md`を更新
5. `log.md`に1行追記: `## [YYYY-MM-DD] ingest | 素材名`

**現状特有の指示:** 素材はすでに大量にある状態。一度に全部読み込ませず、
1素材ずつ「これを読んで」と渡す。1回のセッションで無理に全部終わらせない。

### Query(相談・壁打ち)
台本のアイデアが欲しい、キャラの一貫性を確認したいなど:
- 関連する`wiki/stories/`と`wiki/characters/`を読んでから回答する
- 良いアイデアが出たら、雑談で終わらせず`wiki/stories/`や`wiki/scripts/`に書き足す

### Lint(定期チェック)
- 元ネタが指定されていない`stories/`ページがないか
- 誰にもリンクされていない孤立キャラクターページがないか
- 同じネタが複数のstoriesファイルに重複していないか

## 命名規則
- ファイル名は日本語OK、スペースの代わりに `_` を使う(例: `渋谷の女王_ミナ.md`)
- 各wikiページの冒頭にYAML frontmatterを付ける:
```yaml
---
type: character | story | script | deliverable
status: draft | in-progress | done
updated: YYYY-MM-DD
---
```
